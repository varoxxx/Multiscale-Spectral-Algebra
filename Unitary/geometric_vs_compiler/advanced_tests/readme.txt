# Summary of Validation Tests

## 1. Large‑Scale Haar Unitary Matching (10‑Qubit, 1024×1024)

This test evaluates the geometric optimizer on a high‑dimensional Haar‑random
unitary generated by Qiskit. The target matrix is 1024×1024 (10 qubits), with
no internal structure, symmetries, or circuit decomposition. Haar unitaries
represent the hardest possible matching targets because they are maximally
random.

## 2. Circuit‑Derived Unitary Matching + Circuit‑Execution Validation

This test evaluates the optimizer on unitaries generated by actual Qiskit
circuits containing random U(2) rotations and random CNOT entanglers. The goal
is to verify that the geometric optimizer can reproduce the unitary of a real
quantum circuit and that the resulting unitary behaves identically when used
inside the circuit.

## 3. Haar‑Unitary Scaling Tests (2–5 Qubits)

These tests measure how the geometric optimizer performs as the size of the
Haar‑random target unitary increases. For each qubit count (2, 3, 4, and 5),
Qiskit is used to generate a fully random Haar unitary with no structure or
circuit decomposition. The optimizer then collapses the identity matrix toward
each target using the full geometric pipeline (deviation operator, extremal
spectral projector, geometric update rule, and polar re‑unitarization).

## 4. Unitary Matrix Recovery

This script evaluates a non-standard capability of the geometric operator
framework: recovering a clean unitary from a deliberately corrupted (noisy)
version of itself. Unlike typical quantum compilation, synthesis, or
transpilation tools—which do NOT attempt to repair noisy unitaries—this test
uses the geometric optimizer to pull a perturbed unitary back toward its clean
target using deviation geometry, extremal spectral steering, and polar
re‑unitarization.

## 5. Geometric vs Qiskit Circuit Synthesis (2–3 Qubits)

This test compares the geometric optimizer against Qiskit’s circuit-based
unitary synthesis. For each Haar-random target unitary, two independent
approaches are evaluated:

1. **Geometric matching** — collapse the identity toward the target using
   deviation geometry, extremal spectral steering, and polar re‑unitarization.

2. **Qiskit circuit synthesis** — embed the target unitary into a Qiskit
   circuit and reconstruct the resulting circuit unitary.

Three fidelities are computed:
- **Geometric fidelity to target**
- **Circuit fidelity to target**
- **Geometric vs circuit fidelity**

This test shows how closely the geometric optimizer matches the Haar target
relative to Qiskit’s circuit reconstruction. Because Haar unitaries have no
structure, this comparison provides a clean benchmark of synthesis accuracy.
Perfect or near-perfect geometric fidelity indicates that the collapse geometry
can reproduce the same unitary behavior as circuit-based synthesis without
requiring gates or decomposition.

## 6. Structured Unitary Manifold Tests

This script validates the geometric operator framework across multiple
structured unitary manifolds. Each manifold represents a mathematically
defined subspace of U(N), and the purpose of this suite is to confirm that
the geometric collapse machinery can reproduce the target unitaries *exactly*
(up to global phase) using only the projectors and update rules defined in
the operator geometry.

## 7. Deep Circuit Stress Tests

This script performs the first full-scale evaluation of the geometric
operator framework on *actual deep quantum circuits* — not structured
manifolds, not toy unitaries, not diagonal or block projections, not
tensor-factor targets, and not QFT-only cases. These are real, multi-layer,
entangling circuits built by Qiskit, converted to full unitaries, and then
reproduced purely through geometric descent.
